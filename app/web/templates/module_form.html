So funktioniert ein Modul — Schritt für Schritt

  1. Name (Pflicht): Kurz-Kennung für das Thema, z.B. Vereinsnachrichten. Wird automatisch zu vereinsnachrichten normalisiert und kann später nicht mehr geändert werden.
  2. Aktiviert: Nur aktivierte Module laufen beim automatischen Zeitplan-Lauf und über „Jetzt ausführen“ mit.
  3. Suchtyp: Websuche für allgemeine Themen (Firmen, Produkte, Konkurrenz), News-Suche für Aktuelles mit Datumsangabe (Presse, Veranstaltungen, Fördernews).
  4. Suchanfragen (Pflicht, eine pro Zeile): 2–5 breite Anfragen genügen — die Feinarbeit macht Ollama. Beispiel:
    Musterverein Region XY
    Vereinsheim Neuigkeiten Region XY
    Förderprogramme Vereine 2026
  5. Ollama-Anweisung (optional): Steuert, wie der Report aufbereitet wird (Stil, Struktur, Schwerpunkt). Leer lassen = neutrale Standard-Zusammenfassung mit Quellen-Links. Beispiel: Schreibe im Stil einer Vereinszeitung: kurze Sätze, freundlich, Termine fett hervorheben.
  6. Zeitplan: Standard ist der globale Zeitplan aus den Einstellungen. Mit „Eigener Zeitplan“ läuft genau dieses Modul täglich/wöchentlich zu seiner Uhrzeit — oder nur manuell, wenn „Automatisch laufen“ aus ist.

Ablauf nach dem Speichern: Brave Search liefert Rohdaten (kostet Budget) → Ollama fasst lokal ausführlich mit Quellen-Links zusammen → Report landet lokal unter reports/ und erscheint auf dem Dashboard.

4. Zeitplan (automatisch oder nur manuell)

Standard für dieses Modul: globaler Zeitplan aus den Einstellungen (derzeit: {{ sched.global_human }}). Mit eigenem Zeitplan läuft genau dieses Modul zu seiner Zeit — als eigener System-Timer.

Der Zeitplan wirkt erst, nachdem die Timer angelegt wurden: Installer erneut laufen lassen oder als root python -m app.schedule_units --apply im App-Ordner.
